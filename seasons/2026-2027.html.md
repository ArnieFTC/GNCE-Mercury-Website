## The robot

### The Mercinator (V1)

Version 1 of The Mercinator is a pollen-only robot, built on the same ideas as the DECODE robot we took to States.

![The Mercinator, our BIOBUZZ robot, fully built (version 1)](https://mercury26413.org/images/mercinator_v1_fullybuilt.webp) · ![The Mercinator V1 on a workbench while it was being built](https://mercury26413.org/images/mercinator_v1.jpg)

*The Mercinator, version 1: fully built (left) and on the workbench (right). The robot is still in progress.*

GNCE Mercury, FTC 26413 · BIOBUZZ, 2026–27

**How it scores:** Pollen only (V1)  
**Drivetrain:** Mecanum
